# body'oS 💻

body'oS is a small web-based operating system interface I made for the Stardance WebOS 1 mission.

I wanted to keep it simple and make it feel like my own instead of copying the guide exactly.

## Features

- Multiple windows
- Windows can be dragged around
- Open and close windows
- About window
- Notes window
- Simple Files window
- Taskbar
- Live clock
- No password, so anyone can try it

## How to use

Open the webpage and you will see the body'oS desktop.

Click one of the icons to open a window.

You can drag a window by holding its title bar.

The `×` button closes a window.

The clock on the taskbar shows the current time.

## Tech Stack

- HTML
- CSS
- JavaScript

No frameworks or libraries are used.

## How to run

You don't need to install anything.

Just open `index.html` in a web browser.

You can also use a simple local server such as VS Code's Live Server extension if you want to run it that way.
